## Left, with the reason

| What | Why it was left |
|---|---|
| Grok 1, Codex 5: the 81-creature collision cost and the unproven hardware matrix | A broadphase has to move with each body inside the tick; a grid built once per tick would change who blocks whom, so it needs a route-fingerprint check on every map. Grok measured a 1.3 ms mean and 3.8 ms maximum step on this machine, and the project's 13.4 ms soak spike did not recur. The owner's testers answer the hardware question |
| Grok 3-5, 7, 8, 10; Gemini 5 and 8: per-frame allocations, the version string, monolithic `step` and `render`, the yaw never wrapped, a material clone per punt, the floor-truth test's run time | Measured negligible or maintainability only; each would be a behaviour-neutral change to code that stales every map's evidence for no measured gain |
| Grok 6: intro lines and the tally are written as HTML | A latent sink with no payload: all 68 maps' intros, outros, names, messages, key labels and objectives were scanned for `<`, `>` and `&` and none has any |
| Gemini 7: `voidFall` puts the player back on `p.lastSafe` without re-checking the cell | The code confirms there is no re-check. A door or a creature standing in that cell when the player lands is possible but unobserved; a push-out happens on the next move. Plausible, minor |
| Codex 6, the other half: the verification tools (`browser-check.mjs`, `render-census`, `verify-map` and the rest) are not part of any hash | Versioning the producers needs a design (which files, and what counts as a change to a measurement procedure). The lockfile half is done |
| Codex 8: all 68 maps and the whole texture set load before the title | A design tradeoff; measure cold start before changing it |
| Codex (voice): numbers and geometry sound like a manual in HULL's mouth (C1E4M01 "Thirty if it catches you", C2M13 "an oil a second", and others) | Taste, and precise teaching has a use; not rewritten |
| Grok job 3, 5-8, 10: the minimap's look, a white slab on the Hollow Stair, a crate through the bottom of the view on C2M14, the gun hiding the aimed-at enemy, distant fighters reading as one red coat | Look and taste, or a capture artefact; the crate and the slab are worth a look when someone plays those maps |
