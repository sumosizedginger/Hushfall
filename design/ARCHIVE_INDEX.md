## Rules from here on (also in `AGENTS.md`, "Repo hygiene")
- The repo root holds the project documents named in `AGENTS.md` "Persistent files", the package files, the three HTML pages, the vite config and the folders `assets attack design maps maps-dev maps-src review routes src tests tools validation`. Anything else is a mistake.
- `review/` is OUTPUT. A tool may write a folder of stills there; when the task is finished, the folder goes to the archive (or is regenerated when needed). Keep in `review/` only what a tool reads or what is the current evidence.
- Output of an outside agent: its text goes in `design/audits/` (reports) or `attack/<name>/` (scripts, reports); its images and logs stay out of git.
- Build output is never committed (`dist/`, `attack/**/dist/` are ignored).
- Part two of the tidy (code level: the frozen look demo, one-off `shoot-ptNN` scripts, the gate-2 PNGs) waits until after the evidence regeneration: see `design/COMMERCIAL_AND_USAGE_PLAN.md` "Session T2".
- The "key" that explains the code to other engineers is written when the game is finished (`design/COMMERCIAL_AND_USAGE_PLAN.md` M13), not now.
